Put your images in this folder.

profile.jpg            -> your portrait (square works best, at least 900x900).
                          If this file is missing, the site uses the photo from
                          your previous portfolio automatically.
khoka-tech-logo.png    -> optional. Then set  logo: 'images/khoka-tech-logo.png'
                          in src/config/site.js
projects/<name>.jpg    -> optional project screenshots. Then set  image: 'images/projects/<name>.jpg'
                          for that project in src/config/site.js
